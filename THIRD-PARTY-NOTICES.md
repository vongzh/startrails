# Third-Party Notices

Startrails incorporates runtime-fetched icon URLs and derived open datasets from the following third-party projects:

## 1. sapics/ip-location-db
- **Source**: <https://github.com/sapics/ip-location-db>
- **License**: Open Data Commons Public Domain Dedication and License (ODC PDDL 1.0)
- **Usage**: Optional runtime-fetched CSV datasets (`server-country-ipv4-num`, `server-country-ipv6`, `origin-asn-ipv4-num`, `origin-asn-ipv6`) compiled by `src/server/geo.ts` (`npm run geo:update` or Web UI settings action) into local binary lookup tables under `<dataDir>/geo/`.

## 2. Natural Earth (`ne_110m_admin_0_countries`)
- **Source**: <https://www.naturalearthdata.com/> / <https://github.com/nvkelso/natural-earth-vector>
- **License**: Public Domain
- **Usage**: Derived static rasterized country dot-matrix grid in `web/src/data/world-dot-map.ts`, generated by `scripts/update-world-map.ts` (`npm run worldmap:update`).

## 3. Microsoft Fluent Emoji
- **Source**: <https://github.com/microsoft/fluentui-emoji>
- **License**: MIT License
- **Usage**: Referenced CDN URLs (`fluentui-emoji` 3D PNG assets via jsDelivr) emitted optionally as proxy-group icons for clients such as mihomo and Surge when `groupIcons` is set to `auto`. No image assets are bundled in the repository.

## 4. Twemoji
- **Source**: <https://github.com/jdecked/twemoji>
- **License**: CC-BY 4.0 (graphics) / MIT License (code)
- **Usage**: Referenced CDN URLs (`twemoji@15.1.0` 72x72 flag PNG assets via jsDelivr) emitted optionally as country-flag icons for policy groups when `groupIcons` is set to `auto`. No image assets are bundled in the repository.
